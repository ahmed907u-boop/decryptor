  2. Save this HTML file as index.html in the same folder.
  3. Click the button below to download server.js into the same folder.
  4. Open a terminal in that folder and run:
    npm install express multer
    node server.js
  5. Open your browser at http://127.0.0.1:8080 (the page will load, and the API works on the same origin).
